# LitSearch v0.6.0 Release Notes

## Summary

v0.6.0 expands LitSearch's multi-source literature retrieval architecture,
adds metadata enrichment, strengthens source-specific search behavior, and
completes release-level validation across search, pagination, filtering,
deduplication, exports, and the federated All Sources workflow.

LitSearch now integrates six primary literature retrieval sources:

- PubMed
- Europe PMC
- OpenAlex
- Semantic Scholar
- Crossref
- DOAJ

## Highlights

- Added Crossref as a primary literature retrieval source.
- Added DOAJ as a primary literature retrieval source.
- Expanded All Sources retrieval to six sources.
- Added a centralized connector capability registry for source- and
  mode-specific sorting, filtering, pagination, and result-window behavior.
- Added metadata enrichment architecture with provenance-aware merging.
- Added PubMed MeSH enrichment for paper details.
- Added OpenCitations citation and reference count enrichment.
- Added stable Redis-backed snapshot pagination for All Sources.
- Improved source-specific pagination and navigation behavior.
- Enforced navigable result windows for Crossref and DOAJ.
- Expanded automated and manual release validation.

## Search and Pagination

Search behavior is capability-driven because upstream APIs do not expose
identical functionality.

Notable behavior includes:

- PubMed supports relevance and newest-first sorting.
- Europe PMC uses cursor-based pagination and relevance sorting.
- OpenAlex supports relevance, newest-first, and oldest-first sorting.
- Crossref supports relevance, newest-first, and oldest-first sorting with a
  10,000-record navigable result window.
- DOAJ supports relevance sorting with a 1,000-record navigable result window.
- Semantic Scholar uses separate relevance and chronological retrieval modes.
- Semantic Scholar relevance mode does not expose last-page or direct page-jump
  navigation and has a 1,000-record result window.
- Semantic Scholar chronological mode uses token-based pagination.

## All Sources

All Sources now federates retrieval across PubMed, Europe PMC, OpenAlex,
Semantic Scholar, Crossref, and DOAJ.

The centralized pipeline:

1. retrieves source candidates concurrently;
2. isolates individual source failures;
3. combines the candidate sets;
4. deduplicates cross-source records;
5. applies deterministic relevance interleaving or chronological ordering;
6. stores the ordered result set as a Redis-backed snapshot;
7. paginates over that stable snapshot.

All Sources operates on a bounded candidate pool and is therefore not an
exhaustive representation of every matching record available from every
upstream source.

## Metadata Enrichment

Metadata enrichment is separated from primary literature retrieval.

Implemented paper-detail enrichment providers include:

- PubMed MeSH
- OpenCitations citation and reference counts

Enrichment uses a centralized merge policy, preserves retrieval identity,
records metadata provenance, and follows best-effort behavior so an unavailable
enrichment provider does not discard the retrieved paper.

## Exports

CSV, RIS, and XLSX export workflows remain available, including asynchronous
export generation through Redis and ARQ.

Release validation covered source-specific exports, All Sources exports,
current-page exports, representative RIS output, XLSX output, and asynchronous
export jobs.

## Validation

Final post-fix local validation results:

- Non-integration suite: 273 passed, 7 skipped, 21 deselected.
- Integration suite: 21 passed, 279 deselected.
- Docker application, ARQ worker, and Redis services healthy.
- Manual source validation completed for all six retrieval sources.
- All Sources pagination, sorting, filtering, deduplication, provenance, and
  graceful source-failure behavior validated.
- Export workflows validated.
- Crossref and DOAJ result-window pagination regressions identified during
  release validation were fixed and revalidated.

The Crossref and DOAJ pagination fixes were merged in PR #93.

## Performance

The configured All Sources candidate limit remains 2,000.

Three cold v0.6.0 All Sources measurements produced total request times of
approximately 17.46 s, 5.96 s, and 2.35 s, with a median of approximately
5.96 s. External API latency accounted for substantial run-to-run variability,
while measured internal deduplication, sorting, and pagination overhead remained
small.

Historical v0.5.0 documentation records the performance configuration and
investigation but does not contain a quantitative timing baseline. A numerical
v0.5.0-to-v0.6.0 performance comparison is therefore not available.

## Known Limitations

- All Sources operates on bounded per-source candidate retrieval rather than
  exhaustive upstream result sets.
- Source capabilities for sorting, filtering, and pagination are not uniform.
- Crossref navigation is limited to the first 10,000 records.
- DOAJ navigation is limited to the first 1,000 records.
- Semantic Scholar relevance-mode retrieval is limited to the first 1,000
  records and does not support direct page jumps or last-page navigation.
- Metadata enrichment is currently applied to paper detail requests rather than
  to complete search result sets or exports.
- External API availability, latency, rate limits, and upstream metadata quality
  can affect retrieval behavior.

## Decision

v0.6.0 has completed functional release-level validation. The final release
candidate passed CI on the tagged release commit, and v0.6.0 is approved for
release.
