# LitSearch v0.7.0 Roadmap

## Goal

LitSearch v0.7.0 improves search precision by introducing identifier-based and bibliographic search capabilities.

The release builds on the stable v0.6.0 architecture and preserves the following principles:

- Centralized retrieval pipeline
- Uniform Paper model
- Centralized cross-source deduplication
- Connector-independent architecture
- Explicit source capability semantics
- Reproducible and transparent search behavior

## Release Scope

The primary focus of v0.7.0 is search functionality.

Required scope:

- Identifier-based search: DOI, PMID, PMCID
- Bibliographic search: exact title, author, journal
- Integration with existing retrieval and detail workflows
- Regression testing and release-level validation

Conditional scope:

- Publication type filtering
- Language filtering
- Open Access filtering

Conditional features require a capability assessment and explicit inclusion decision before implementation.

# 6. Deferred Beyond v0.7.0

The following features are not part of the initial v0.7.0 scope:

- Institution and affiliation filtering
- BASE integration
- arXiv integration
- Additional metadata enrichment providers
- Citation graph functionality
- New export formats
- Authentication and user accounts
- Saved searches
- AI-assisted interpretation of papers
- Full UI redesign

---

# 7. Development Principles

- Use feature branches and pull requests
- Write focused tests before implementing behavior
- Prefer small, reviewable changes
- Preserve backward compatibility where possible
- Reuse existing connector functionality
- Avoid introducing duplicate retrieval logic
- Document important design decisions
- Keep roadmap checkboxes aligned with verified implementation
- Do not release with failing required CI checks
